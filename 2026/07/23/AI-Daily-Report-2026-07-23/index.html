AI 每日深度调研报告(2026-07-23):Opus 5 半价回应、Codex 预热"codexy"、模型价格战开打

发表于 2026-07-23 分类于 AI前沿

2026-07-23,AI 格局三大主线浮现:Anthropic 发布 Opus 5(Fable 5 级智能、半价,回应 Opus 4.8 落后 GPT 5.6/GPT 5.5/开源 Kimi K3 的困局)、OpenAI 协调预热 Codex(tibo 和 @ajambrosino 同天用”codexy”这个生造词,暗示 7/24 有 Codex 大更新)、模型价格战开打(Opus 5 半价 + Kimi K3 开源 + GPT 5.6 竞争,模型从壁垒变成商品)。本文梳理当日 3 大事件,提炼 2 个趋势洞察,做模型横向对比。

一、当日重大事件梳理

1.1 Anthropic 发布 Opus 5:Fable 5 级智能,半价

事实:@bridgemindai 报道,Claude Opus 5 今天发布。核心卖点:Fable 5 级别智能,但只要半价。背景是 Opus 4.8 已经落后整个前沿–GPT 5.6、GPT 5.5、甚至开源的 Kimi K3 都超过了它。”The best model in the world at half price?”

分析:这是 Anthropic 对 Opus 4.8 落后的正面回应,而且选择了一个攻击性极强的定价策略–半价。这意味着:

  1. 能力追平:Opus 5 对标 Fable 5,不再是”落后者”
  2. 价格武器:半价不是成本下降,是主动降价抢市场–Anthropic 在用价格战回应 OpenAI
  3. 承认落后: indirectly 承认 Opus 4.8 确实掉了队,需要新产品重夺前沿

参考:x.com/bridgemindai/status/2080258553885999217

1.2 OpenAI 协调预热:Codex 7/24 大更新

事实:tibo(@thsottiaux,OpenAI 员工)发推”Unbelievable excited for what’s coming together. Tomorrow is feeling codexy”。同日,@ajambrosino 发推”feeling very codexy today and also quite chatty”。两个相关账号同天使用”codexy”这个新造词。

分析:这是典型的产品发布前协调预热:

  1. 新造词指向产品线:”codexy”明确指向 Codex 产品线
  2. “chatty”暗示功能:”chatty”可能暗示对话/聊天相关的 Codex 新功能
  3. 多人同时用同一生造词 = 有意放风:不是巧合,是协调的预热节奏
  4. 时间线:tibo 说”tomorrow”(7/23 发,即 7/24),7/24 大概率有 Codex 大更新

怎么读这种信号:当多个相关账号在同一天开始使用一个新造词,且该词指向特定产品线,通常意味着该产品线即将有重大发布。这是 AI 行业常见的”软预热”模式。

参考:

  • x.com/thsottiaux/status/2080144499716800513
  • x.com/ajambrosino/status/2080288681311748167

1.3 模型价格战正式开打

事实:Opus 5 以半价发布,叠加近期 Kimi K3 开源(免费)、GPT 5.6 持续竞争,前沿模型的价格正在快速下降。Opus 4.8 曾因能力落后 + 价格不具竞争力而掉队,Opus 5 直接半价回应。

分析:模型价格战正式开打,标志着:

  1. 能力趋同:前沿模型能力已接近,价格成为新战场
  2. 半价不是成本下降:是主动降价抢市场份额的战略选择
  3. 开源压力:Kimi K3 开源免费,逼着闭源模型降价
  4. 用户受益:前沿模型从 $XX 降到半价,开发者用更低成本拿到更强能力

参考:x.com/bridgemindai/status/2080258553885999217

二、趋势洞察

趋势一:模型从”壁垒”变成”商品”,价格成为新战场

Opus 5 半价发布 + Kimi K3 开源 + GPT 5.6 竞争,标志着前沿模型正在从”能力壁垒”变成”商品”。当模型能力趋同,竞争维度从”谁最强”转移到”谁最便宜”。

演变路径:

  1. 2025 年:模型能力是护城河,GPT/Claude 独占前沿
  2. 2026 年初:开源模型追上,但被质疑”刷分”
  3. 2026-07:Kimi K3 实测打平 + 前端第一 + 供不应求 + 开源
  4. 2026-07-23:Opus 5 半价回应 – 价格战确认

深层逻辑:模型能力正在从”壁垒”变成”商品”。当模型能力趋同,竞争维度转移到:① 分发渠道(Copilot/Claude Code/Codex) ② 数据和场景 ③ 生态(skill/plugin/MCP) ④ 价格。有”最好模型”不再是护城河,有”最好分发 + 最好价格”才是。这对开发者是利好–前沿能力越来越便宜;对模型公司是挑战–纯靠模型能力已经赚不到超额利润。

趋势二:AI 产品发布的”软预热”模式

tibo 和 @ajambrosino 同天用”codexy”预热 7/24 Codex 更新,展示了一种 AI 行业特有的产品发布模式–”软预热”。

模式拆解:

  1. 生造词信号:创造一个新词(“codexy”)指向特定产品线
  2. 多人协调:多个相关账号同天使用该词,形成共振
  3. 模糊暗示:不直接说发布什么,用”chatty”等词暗示功能方向
  4. 时间锚点:用”tomorrow”等时间词锁定发布窗口

为什么用软预热:比官方公告更有传播力–引发社区猜测和讨论,形成自然话题热度。同时保持”否认空间”–如果延期,可以说只是随便聊聊。

对读者的价值:学会读这种信号,能在官方公告前 1-2 天预判产品发布,提前准备(写测评、做对比、调整技术选型)。
