CC Switch：一款桌面工具统一管理 Claude Code、Codex、Gemini CLI 等 AI 编程助手

发表于 2026-05-30 分类于 AI工具

一、为什么需要 CC Switch？

2026年的 AI 编程工具生态已经进入”三国演义”时代：Claude Code、Codex、Gemini CLI 各有优势，很多开发者同时使用多个工具。但每个工具都有自己的配置格式——Claude Code 用 JSON，Codex 用 TOML，Gemini CLI 用 YAML。切换 API 提供商意味着手动编辑不同的配置文件，管理 MCP 服务器和 Skills 更是分散在各个工具的不同目录中。

CC Switch 正是为解决这个痛点而生。它由 Jason Young（@Jason_Young1231）开发，是一个基于 Tauri 2 构建的跨平台桌面应用，目前在 GitHub 上已获得广泛关注。

二、核心功能

2.1 一个应用，管理六个 CLI 工具

CC Switch 支持统一管理以下 AI 编程 CLI 工具：

工具 开发商 特点
Claude Code Anthropic 终端 AI 代理，深度理解代码库
Codex OpenAI 云端异步执行，开源 CLI
Gemini CLI Google 超长上下文，免费额度慷慨
OpenCode 社区 开源替代方案
OpenClaw 社区 多技能系统
Hermes Agent 社区 社区驱动的 AI 代理

2.2 50+ API 提供商预设

CC Switch 内置了 50 多个 API 提供商预设，包括：

  • 官方渠道：Anthropic、OpenAI、Google
  • 云服务商：AWS Bedrock、NVIDIA NIM、火山引擎
  • 社区中继：PackyCode、AIGoCode、CrazyRouter、RunAPI 等
  • 国内平台：硅基流动、DeepSeek、豆包等

只需复制 API Key，一键导入即可切换，无需手动编辑配置文件。

2.3 统一 MCP 和 Skills 管理

这是 CC Switch 最实用的功能之一：

  • MCP 统一面板：在一个界面管理所有工具的 MCP 服务器，支持双向同步
  • Skills 一键安装：从 GitHub 仓库或 ZIP 文件一键安装 Skills，支持自定义仓库管理
  • 跨应用同步：MCP 和 Skills 配置可以在 Claude Code、Codex、Gemini CLI 之间同步

2.4 系统托盘快速切换

CC Switch 安装后会在系统托盘常驻，右键即可快速切换 API 提供商，无需打开完整界面。这对于需要频繁切换不同模型或提供商的开发者来说非常方便。

2.5 云端同步

支持通过 Dropbox、OneDrive、iCloud 或 WebDAV 服务器在多台设备间同步提供商数据，在办公室和家里使用不同电脑时保持配置一致。

2.6 用量和成本追踪

内置用量仪表盘，可以追踪：

  • 各工具的 API 调用次数和 Token 消耗
  • 费用趋势图表
  • 详细的请求日志
  • 自定义每模型定价

三、安装和使用

3.1 下载安装

前往 CC Switch 官方网站 ccswitch.io 或 GitHub Releases 页面下载对应平台的安装包：

  • Windows：.msi 或 .exe 安装包
  • macOS：.dmg 安装包
  • Linux：.AppImage 或 .deb 安装包

3.2 添加提供商

  1. 打开 CC Switch，点击”添加提供商”
  2. 从 50+ 预设中选择你的 API 提供商
  3. 输入 API Key
  4. 点击”导入”，CC Switch 会自动配置到对应的 CLI 工具

3.3 切换提供商

两种方式：

  • 主界面切换：在提供商列表中点击目标提供商
  • 托盘切换：右键系统托盘图标，选择提供商

3.4 管理 MCP 和 Skills

  • MCP：在统一面板中添加、删除、编辑 MCP 服务器配置
  • Skills：从 GitHub 仓库一键安装，或手动上传 ZIP 文件

四、技术架构

CC Switch 基于 Tauri 2 构建，这是一个用 Rust 编写的跨平台桌面应用框架：

  • 前端：React + TypeScript
  • 后端：Rust（Tauri 核心）
  • 数据库：SQLite（原子写入保护配置不损坏）
  • 构建：支持 Windows、macOS、Linux 三平台

Tauri 相比 Electron 的优势是更小的安装包体积和更低的内存占用。

五、社区生态

CC Switch 拥有活跃的社区生态：

  • 15+ API 中继服务商赞助：包括 PackyCode、AIGoCode、CrazyRouter、RunAPI 等
  • CC Academy：官方教程平台，提供详细的使用指南
  • GitHub 社区：活跃的 Issue 讨论和 PR 贡献
  • v3.15 最新版：持续更新，功能不断增强

六、使用建议

6.1 适合谁使用？

  • 多工具开发者：同时使用 Claude Code + Codex + Gemini CLI
  • 需要切换 API 提供商的用户：比如官方额度用完后切换到中继服务
  • 团队协作：需要统一管理多个开发者的 AI 工具配置
  • 成本敏感用户：通过用量追踪优化 API 消耗

6.2 配合 Claude Code 的最佳实践

CC Switch 与 Claude Code 配合使用时：

  1. 提供商管理：在 CC Switch 中配置多个提供商（官方 + 中继），额度用完一键切换
  2. MCP 同步：在 CC Switch 中统一管理 MCP 服务器，避免手动编辑 .mcp.json
  3. Skills 管理：通过 CC Switch 的 Skills 面板一键安装社区 Skills
  4. Prompt 管理：统一编辑 CLAUDE.md / AGENTS.md，支持跨应用同步

七、总结

CC Switch 解决了 AI 编程工具碎片化的核心痛点。在一个桌面应用中，你可以：

  • ✅ 统一管理 Claude Code、Codex、Gemini CLI 等六个 CLI 工具
  • ✅ 一键切换 50+ API 提供商
  • ✅ 统一管理 MCP 服务器和 Skills
  • ✅ 追踪用量和成本
  • ✅ 跨设备云端同步

如果你同时使用多个 AI 编程工具，CC Switch 值得一试。
