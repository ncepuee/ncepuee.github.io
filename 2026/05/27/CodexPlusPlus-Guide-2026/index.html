Codex++：解锁 Codex App 全部潜力的增强神器

发表于 2026-05-27 更新于 2026-08-30 分类于 AI工具

一、Codex 用户的常见痛点

OpenAI Codex 是一款强大的 AI 编程助手，但在使用过程中，不少用户会遇到以下问题：

  • 插件功能被锁定：使用 API Key 登录后，插件功能直接被禁用，提示”需要登录 ChatGPT”才能使用
  • 无法删除会话：会话列表只有”归档”按钮，没有真正的删除入口
  • 网络连接问题：加载技能时频繁提示 GitHub 连接失败，特别是国内网络环境下

这些问题并非无解。Codex++ 正是为解决这些痛点而生的社区开源项目。

二、Codex++ 是什么？

Codex++ 是一个面向 Codex App 的外部增强启动器。它的设计理念非常优雅——不修改任何 Codex App 原始安装文件，而是通过外部 launcher 启动 Codex，并使用 Chromium DevTools Protocol (CDP) 向渲染进程注入增强脚本。

这种方式的好处显而易见：

  • ✅ 不会破坏 Codex 的原生安装
  • ✅ 不会写入 DLL 或修改 app.asar
  • ✅ Codex 更新后仍然可以使用
  • ✅ 安全可控，不涉及敏感操作

三、核心功能

3.1 插件功能解锁

在 API Key 登录模式下，Codex 原生会禁用插件入口，导致无法使用各种强大的插件功能。Codex++ 启动后会自动解锁插件入口，让你在 API Key 模式下也能畅快使用所有插件。

3.2 会话删除功能

Codex 原生的会话列表只有”归档”按钮，没有真正的删除功能。Codex++ 提供了完整的删除体验：

  • 悬停显示删除按钮：鼠标移到会话上即出现”删除”按钮
  • 删除前确认：防止误操作
  • 支持撤销：删错了可以立即恢复
  • 双重删除机制：优先尝试服务端删除；不可用时自动删除本地 Codex SQLite 会话记录

3.3 可视化配置界面

Codex++ 在顶部菜单栏加入了专属菜单，点击即可打开配置界面，轻松开关各种功能：

  • 插件选项解锁
  • 特殊插件强制安装
  • 会话删除功能

3.4 自动代理探测

Codex 加载技能资源需要访问 GitHub，但国内网络环境下经常不稳定。Codex++ 启动时会：

  1. 自动继承现有的 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY 环境变量
  2. 如果未设置，会自动探测常见本地代理端口（如 127.0.0.1:7897）
  3. 帮助 Codex 顺利加载需要访问 GitHub 的技能资源

四、工作原理

Codex++ 的技术架构非常清晰：

关键设计决策：

  • 不开放 HTTP 删除/撤销入口：避免本机其他页面误触发删除类操作
  • 通过 CDP bridge 通信：渲染进程与本地服务之间通过 Chrome DevTools Protocol 桥接
  • 外部启动器模式：不修改 Codex 任何原始文件，更新兼容性好

五、项目地址与使用

Codex++ 是一个社区驱动的开源项目，项目地址：

👉 https://github.com/BigPizzaV3/CodexPlusPlus

使用方式：

  1. 从 GitHub Releases 下载最新版本
  2. 启动 Codex++ Launcher
  3. Codex++ 会自动启动 Codex App 并注入增强功能
  4. 通过顶部菜单栏的 Codex++ 菜单进行配置

六、总结

Codex++ 解决了一个很实际的问题：API Key 用户在享受更低价格和更高灵活性的同时，往往失去了部分产品功能。Codex++ 通过外部增强的方式，在不破坏原生安装的前提下，补齐了这些功能缺口。

这种**”外部启动器 + CDP 注入”**的设计思路也值得借鉴——不修改目标应用本身，而是通过标准协议进行扩展，既保证了兼容性，又降低了使用风险。
