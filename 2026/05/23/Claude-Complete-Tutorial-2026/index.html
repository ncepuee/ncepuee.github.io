Claude Code 从零到一完全教程：安装、使用到高级扩展

发表于 2026-05-23 分类于 AI工具

前言

Claude Code（简称 CC）是 Anthropic 公司 2025 年 2 月推出的、运行在终端中的 Agent 程序。最初为编程而生，但现在已经可以胜任文案、数据分析、报告生成等各类脑力工作。

这篇教程会从零开始，带你一步步了解 CC——从装好它、用起来，到管住它、让它个性化地服务你，最后学习它的高级扩展功能。

一、CC 是什么：Agent 的工作原理

CC 的核心运行机制叫做 LM Loop（大模型循环）：

为什么 CC 比网页 Agent 更强？

第一，CC 运行在你的电脑上——它可以在有限权限下直接访问和读写本地文件、使用终端、执行命令。

第二，CC 的 Harness 工程做得更好。Harness 是 Agent 程序中除了大模型之外，让 Agent 表现更好的所有设计的统称。即便用同样的大模型，更好的 Harness 也会带来巨大的效果差异。

CC 能做什么？

  • 编程开发 — 即使没有编程基础也可以做出可用的应用
  • 文案写作、资料查询、数据分析
  • 做表格、做报告
  • 更多你定制的专属任务

Anthropic 内部员工很早就在用 CC 处理法律、财务、市场等各类任务。

二、安装与配置

使用方式（四种）

  1. Claude 官方桌面应用
  2. 网页版
  3. IDE 插件 — Cursor、Antigravity、Trae 等
  4. 终端（推荐） — 功能最全、更新最快

本教程采用终端 + IDE 搭配的方式。

安装 CC

方式一：一行命令安装

方式二：让 Agent 帮你安装
在 IDE 的 Agent 中输入安装指令，它自己处理依赖和网络问题。

配置大模型：CC Switch

由于 Claude 账号实名制的限制，国内用户更适合使用国产大模型 API。推荐使用 CC Switch 来管理和切换多个模型：

  1. 下载并安装 CC Switch
  2. 填入 API Key 和 Base URL
  3. 配置多组 Key，随意切换档位

注意： 必须在启动 CC 之前打开 CC Switch，否则它会默认引导你去登录 Claude。

首次启动

进行初始设置：选择主题色 → 安全确认 → 推荐设置 → 确认文件夹可信。

三、三种权限模式

CC 有三大核心模式，通过 Shift+Tab 循环切换：

模式 行为特点
Plan Mode（计划模式） 先出详细计划，等你确认后才动手
默认模式 自动判断哪些要问你、哪些直接做
自动编辑模式 改文件不询问，但执行命令仍需同意

极速模式（一路绿灯）：

此模式下 CC 完全不会征得你的同意。Anthropic 发现 93% 的情况用户其实都会直接同意，所以这是一个值得考虑的选项。

四、与 CC 交互的方式

1. 文字对话（最基础）

2. 添加文件（精准给上下文）

  • 使用 @ 或 add 指定具体文件
  • 也可直接拖拽文件到对话框
  • 较长的指令建议先在本地写好文件，再 add 给 CC

冷知识： 给 CC 的指令越短，它花费的 Token 可能越多——因为指令不足时它会花费更多 Token 去探索你的本地文件。

3. 图片输入（多模态）

  • 拖拽或 Ctrl+V 粘贴图片
  • Mac 上也是 Ctrl+V（不是 Cmd+V）

4. 斜杠命令速查

命令 用途
/help 查看所有命令
/model 切换高中低档模型
/btw 问和当前任务无关的问题（隔离上下文）
/compact 主动压缩上下文，释放 Token 空间
/new 清空上下文，重开对话
/resume 恢复之前的对话
/init 初始化项目，生成 CLAUDE.md
/contexts 查看详细上下文占用比例
/simplify 派生 3 个子 Agent 做代码审查

换行技巧： Mac = Option+回车，Windows = Ctrl+回车

五、管住 CC：后悔药与上下文管理

后悔药方案

1. 快速撤回： 双击 ESC 或输入 /undo

  • 可撤回：对话内容 + CC 编辑的文件
  • 局限：无法撤回终端执行的操作（如包安装）

2. Git 版本管理（真正的后悔药）
把 Git 理解为”游戏的存档系统”——每完成一个阶段性工作就让 CC 帮你存一次档，随时可以回滚。

养成版本管理的习惯： AI 有不确定性，每做完一步就让 CC 帮你存档，之后会更放心地让它尝试各种方案。

上下文管理

所有 AI 都面临的问题——上下文窗口有限。随着对话增多、文件累积，大模型能力会下降。

两个核心命令：

命令 效果
/compact 压缩上下文，保留关键信息释放空间。CC 也会在上下文快满时自动压缩
/new 彻底清空，重开对话

监控上下文占比：
输入 /contexts 查看详细的 Token 占用，也可让 CC 打开底部实时百分比显示。个人经验：超过 60% 就需要 /compact 一下了。

六、让 CC 记住你是谁：三层记忆体系

第一层：CLAUDE.md（最高优先级，全部注入）

CLAUD.md 是 CC 在对话前第一时刻就会读取的规则文件，分三级：

级别 位置 用途 是否共享
全局 ~/.claude/CLAUDE.md 个人通用规则（如：始终用中文） 仅自己
项目级 项目根目录/.claude/CLAUDE.md 技术架构、开发规范 可提交到 Git 团队共享
文件夹级 子文件夹/CLAUDE.md 针对特定目录的规则 可共享

初始化项目级：

CC 会自动扫描项目，将项目信息写入 CLAUDE.md。

最佳实践： 不要急于一开始就写完 CLAUDE.md。等项目有一定成形后再初始化，随着项目的推进逐步补充 CC 犯过的错和踩过的坑。错误经验积累越多，CC 犯错越少。

第二层：AutoMemory（自动记忆，按需注入）

后台有一个 Agent 在默默地自动记录：

  • 关于用户的信息
  • 你给过的反馈（”不要这样，要那样”）
  • 项目进度、决策、技术选型
  • 外部资源位置

开启方式： /memory → 选择 AutoMemory → 打开

特点： AutoMemory 只作用于当前项目，跨项目需要重新积累。它不会一次全部加载进上下文——每次先读摘要索引，需要时才读取具体文件。

管理记忆： 如果 CC 记错了，直接说”忘掉刚才说的 XXX”即可删除。

第三层：自行构建文本文档

按同样的逻辑，自己写规范文档，然后在 CLAUDE.md 中指定 CC 什么时候去参考。示例：

  • 品牌视觉规范 → 修改 UI 时参考
  • 文案风格指南 → 写产品文案时参考

不论 OpenClaw 还是 Claude Code，所谓的”持久记忆”本质都是在适当的时候向 Agent 注入经过筛选的上下文。

七、高级扩展功能

Skills（技能）

Skills = 给 AI 的子领域专业说明书和操作手册。

四种类型：

类型 说明 示例
知识型 领域规范手册 页面设计规范
流程型 标准操作流程 公司记账报销流程
工具型 工具调用方法 调用 API 生成图片
混合型 以上组合 公众号排版并自动发布

安装方式：

  1. 手动放置： 将 Skill 文件夹放入 ~/.claude/skills/（全局）或项目 .claude/skills/（项目级）
  2. 自动搜索安装： 装 FindSkill → 让 CC 搜索并安装
  3. 斜杠调用： / + Skill 名称

创建自己的 Skill：
用 Skill Creator 和 CC 对话即可创建。不需要手动写，描述你想要什么 Skill，CC 会生成。

MCP（外部工具转接头）

MCP = 连接 AI 和外部工具/服务的中间件。例如让 CC 读取飞书设计稿、访问 Notion 资料库。

不过目前 MCP 占用 Token 较多，不适合同时连接太多服务。轻量的场景转向了 Skills，重量的转向了 CLI。

CLI 工具（当前热潮）

CLI（Command Line Interface）原本是给程序员用的命令行工具，普通用户不会用，但 AI 非常擅长用。比起让 AI 模拟人类操作浏览器（截图、点击、翻页），直接输出命令要精准高效得多。

常见 CLI 工具：

  • 飞书 CLI： 创建文档、写多维表格、发邮件、建日历
  • OpenCLI： 将常用网页和社交媒体的接口封装成 CLI

安装方式： 把地址粘贴给 CC，让它帮忙装好。

Sub-agent（子 Agent）

需要并行处理或不想污染主 Agent 上下文时使用。

  • 自动派生： CC 判断任务适合并行时会自动派生子 Agent（如调研类任务）
  • 手动创建： /agent → 按引导创建

子 Agent 拥有独立的上下文空间，可并行工作，结果汇总给主 Agent。

Hooks（条件反射 / 自动触发器）

设定”当 CC 怎么样时，自动执行什么”。示例：

  • 每次完成任务后自动发出提示音 + 发送通知
  • 每次提交代码前自动触发格式检查

Plugins（插件）

插件 = Skills + Sub-agents + Hooks + MCP 打包在一起。

管理：/plugin 进入插件管理页面 → 发现 / 管理已安装。

八、核心要点总结

  1. CC = 本地运行的 Agent，通过 LM Loop 循环工作
  2. 三种模式：Plan / 默认 / 自动编辑，Shift+Tab 自由切换
  3. 交互方式：文字、文件、图片、斜杠命令
  4. 后悔药：ESC ESC（快速撤回）+ Git（永久存档）
  5. 上下文管理：/compact（压缩）、/new（清空）、/contexts（监控）
  6. 记忆三层次：CLAUDE.md → AutoMemory → 自定义文档
  7. 高级扩展：Skills / MCP / CLI / Sub-agents / Hooks / Plugins
  8. 核心理念：从一问一答到构建系统、组织 AI 让它自己去干

对于新手来说，从安装和基本交互开始就够了；随着使用深入，逐步引入 CLAUDE.md、Git 管理、上下文监控；最后再探索 Skills 和 Sub-agent 等高级功能——让你的 AI 助手从”单兵作战”进化为”团队协作”。
