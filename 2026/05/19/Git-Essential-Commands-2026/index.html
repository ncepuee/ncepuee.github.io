Git 新手必备：最常用的 5 条命令就够了

发表于 2026-05-19 分类于 编程学习

一、前言

Git 是每个开发者都绕不开的工具。但说实话，它的命令又多又抽象，新手很容易被吓到。

其实日常开发中，90% 的场景只需要 5 条命令。先背会这 5 条，剩下的遇到再查。

二、最常用的 5 条命令

1. git status — 看状态

任何时候不确定当前是什么状态，先跑这个。

它会告诉你：改了哪些文件、哪些文件还没提交、当前在哪个分支。这是 Git 的”仪表盘”，随时都可以看。

三、完整 12 条常用命令速查

除了上面 5 条，下面这些也经常用到：

命令 用途
git clone 仓库地址 下载/克隆项目
git log 查看提交历史
git branch 查看所有分支
git checkout -b 新分支名 创建并切换到新分支
git checkout 分支名 切换分支
git checkout . 放弃本地所有修改（还原文件）
git fetch --all && git reset --hard origin/main 强制同步成和远程一模一样

四、几个实用技巧

4.1 当冲突发生时

git pull 后提示冲突怎么办？别慌，冲突文件里会有这样的标记：

手动编辑保留需要的部分，删掉标记行，然后 git add . → git commit -m "解决冲突" → git push。

4.2 .gitignore 很重要

有些文件（编译产物、依赖包、配置文件里的密钥）不应该被 Git 管理。在项目根目录创建 .gitignore 文件，把不需要追踪的文件名写进去：

4.3 每次提交做一件事

一个提交只做一个改动。这样日后查历史、回滚都会方便很多。”修复登录bug”是一个好提交，”修复bug+优化样式+更新文档”就是一个糟糕的提交。

五、总结

Git 入门不需要背几十条命令。先把这 5 条用好：

  1. git status — 看状态
  2. git add . — 添加修改
  3. git commit -m "备注" — 提交
  4. git pull — 拉最新
  5. git push — 推送

不需要花里胡哨的技巧，先跑起来再说。
