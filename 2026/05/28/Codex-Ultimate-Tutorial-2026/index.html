OpenAI Codex 从入门到实战：2026年最新保姆级教程

发表于 2026-05-28 更新于 2026-05-29 分类于 AI工具

一、前言

2026年的 Codex 跟几个月前相比几乎是两个产品。从最初的 CLI 工具，到现在拥有桌面应用、可视化 UI、Skills 插件系统、Computer Use 甚至手机远程控制——Codex 的进化速度令人惊叹。

本文将从零开始，带你全面了解 Codex 的核心功能，并通过两个实战案例（一个网页 + 一个 App）串联起整个使用流程。

二、安装与登录

2.1 下载安装

前提条件：需要科学上网和 ChatGPT 账号。

前往 Codex 官网 下载安装，Mac 和 Windows 都有客户端。

2.2 登录与额度

Codex 的额度与你的 ChatGPT 会员等级挂钩：

计划 价格 适用场景
Plus $20/月 轻度使用，勉强够用
Pro $100/月 日常开发，推荐
Pro+ $200/月 重度使用

也可以使用 API Key 方式接入，看个人需求。

2.3 一键迁移

登录后有一个非常贴心的功能——可以从 Claude Code 和 Cowork 直接导入所有配置。Codex 不光天天重置额度喊你来用，还能帮你一键搬家，继承之前的所有设置和记忆。

三、认识界面

3.1 核心区域

  • 中央对话区：日常与 AI 对话的主区域
  • 左侧栏：管理所有对话和项目
    • 对话：不需要绑定特定文件夹的零碎任务（调研、规划等）
    • 项目：Codex 的主战场，绑定本地文件夹作为工作区间

3.2 项目管理建议

选一个本地文件夹作为项目目录，Codex 会以此为工作区间，所有生成的文件自动存入。一个项目里可以开多个对话，每条对话是独立任务线，共享文件但记录隔离。

建议：同一方向的任务放同一个项目，具体每件事开新对话。前期做好分类，不然后期会很抓狂。

3.3 权限模式

对话框左下角有三档权限：

模式 说明
默认权限 每次操作都需要审批
自动审查 日常开发推荐，只在高风险操作时拦截
完全访问 全部自动运行，不征询确认

3.4 模型与推理设置

对话框右下角可切换：

  • 模型：直接选目前最强的 GPT-5.5
  • 推理等级：日常用”高”就够，遇到硬活再开”超高”
  • 速度：推荐”标准”模式（快速模式是 1.5 倍速但消耗 2 倍 token）

四、关键设置（不能跳过！）

4.1 常规设置

打开左下角设置，务必开启以下三个选项：

  • 常规设置中的自动保存、自动运行等基础功能
  • 跟进行为改为”引导”——这样在任务执行中途可以直接插入修改，不用等做完
  • 记忆功能：开启后 Codex 会在对话结束或闲置后自动总结记忆，下次遇到相关场景自动调用

4.2 AGENTS.md：你的”家法”

这是从上往下分层穿透的约束体系。第一层是全局生效的 AGENTS.md，在个性化设置的自定义指令中修改。

推荐使用 Andrej Karpathy 的模板：

五、Skills 与插件

Codex 将 Skills 和插件做了可视化 UI 管理。在”插件” Tab 中可以切换查看：

  • Skills：给 Agent 用的技能包
  • 插件：一组技能、工具、配置的打包安装包，比单独 Skill 更成熟

右上角可以直接创建自定义 Skill 和插件。要安装第三方资源，直接把链接甩给 Codex 即可。

六、实战一：开发一个网页

6.1 开启计划模式

建好项目文件夹后，点击左侧加号，打开计划模式。这个模式只规划不动手，先帮你理清方案，确认后再执行。

每个稍复杂的项目，都推荐先用计划模式过一遍。

6.2 描述需求

告诉 Codex 你的需求，它会先问几个问题，你点选回答后，它会给出一份完整的方案计划。

6.3 确认并执行

确认方案没问题后，点击开始实施。整个开发过程全自动，这种小网页基本一遍成。

6.4 内置浏览器预览

做完后可以用 Codex 的内置浏览器直接预览效果，支持左右拖动对比。右上角有几个实用功能：

  • 截图：一键截取当前页面
  • 批注（强烈推荐）：直接在页面上圈选元素，写修改意见。比如选中某个 logo，输入”换成官方 logo”，Codex 就能理解并修改。新版本还支持字体、字号、颜色等参数的实时调整。

七、实战二：开发一个 App

7.1 真实需求驱动

以一个真实场景为例：体检后医生开了三种药，一天吃两到三次，有的饭前有的饭后，经常搞混。于是决定做一个手机用药提醒 App。

7.2 同样开启计划模式

描述需求 → Codex 提问 → 回答 → 确认方案 → 自动执行。大约二十分钟后，App 代码自动生成完毕。

7.3 编译安装到手机

开发 App 跟网页不同，需要 Xcode（Mac 上的 iOS 开发工具）来编译。大多数人电脑上可能没有提前安装 Xcode，这里有一个很酷的方法：

用 @Computer Use 插件让 Codex 帮你搜索、下载和安装 Xcode。

Computer Use 是 Codex 上最出色的能力之一——它能视觉化操控你的电脑。使用前需要在设置中开启 Computer Use 开关。

使用过程中电脑上方会显示操控状态提示条。涉及密码输入或账号登录等安全步骤时，Codex 会暂停让你自己操作。

7.4 手机端操作

安装到手机后，可以掏出手机继续远程操作 Codex。这是近期刚上线的新功能，支持 iOS 和 Android 手机连接 Mac 上的 Codex，实现随时随地 Vibe Coding。

八、Mac vs Windows：功能差距

Windows 用户需要注意，目前 Codex 的部分高级功能仅支持 Mac：

功能 Mac Windows
Computer Use（视觉操控电脑） ✅ ❌
远程手机连接 ✅ ❌
Appshots（双击 Command 截屏发送） ✅ ❌
Locked Computer Use（锁屏后继续操控） ✅ ❌
Chronicle（屏幕上下文记忆） ✅ ❌

Mac 用户目前是 Codex 的”高贵 VIP”，Windows 用户还需要等待这些功能的适配。

九、总结

Codex 在2026年已经成为 AI Agent 领域的标杆产品之一。从简单的代码补全到完整的 App 开发，从桌面到手机远程控制，它的能力边界在不断扩展。

几个核心使用建议：

  1. 先设置 AGENTS.md：用 Karpathy 模板打好基础
  2. 善用计划模式：复杂任务先规划后执行
  3. 用好批注功能：在预览页面直接圈选修改，比截图描述高效十倍
  4. 管理好对话：一个任务一条对话，别全堆在一起
  5. Computer Use 是杀手级功能：能让 AI 帮你操作电脑上的其他软件
