我安装的55个AI Agent实用技能盘点：从学术研究到自媒体发布

发表于 2026-05-14 分类于 效率工具

一、前言

最近折腾 AI Agent 上瘾，陆续安装了不少 Skills（技能插件）。这些技能覆盖了从学术论文写作、文献检索、文档处理，到自媒体发布、数据分析等各种场景。今天把它们整理出来，一来方便自己回顾，二来也给大家做个参考——万一有你需要的呢？

先说下这些技能的来源。我目前用的 Agent 平台主要基于 Claude Code + QClaw，技能文件分布在三个目录中：

  • ~/.agents/skills/ — 公共技能库
  • ~/.qclaw/workspace/skills/ — 工作区技能
  • ~/.qclaw/skills/ — QClaw 内置技能

下面按用途分类介绍。

二、学术研究与论文写作

这块是装得最多的，毕竟搞科研是刚需。

2.1 文献检索类

技能名 功能简介
academic-research-hub 统一检索 arXiv、PubMed、Semantic Scholar，下载 PDF、提取引用、生成 BibTeX
arxiv-scholar-search 专门针对 arXiv 的论文搜索，支持多轮搜索策略和相关性筛选
ieee-xplore IEEE Xplore 文献搜索与下载，支持按 arnumber 获取详情和 PDF
literature-search 基于 OpenAlex、Crossref、Unpaywall 的学术搜索，免费无需 API Key
paperwise 论文搜索 + HTML 标注 + 每日摘要，支持 CHI/ACL/NeurIPS 等会议筛选
citation-management BibTeX 引用管理：从草稿中提取缺失引用、去重、格式化

个人感受：academic-research-hub 最实用，一个入口搜多个数据库。literature-search 胜在免费，OpenAlex 不需要 API Key。

2.2 论文写作类

技能名 功能简介
academic-research-skills 全套学术流水线（v2.9）：13 个 Agent 团队做深度研究、12 个 Agent 写论文、10 阶段流程编排
scientific-paper 从问题定义到发表级输出的 6 阶段研究方法论，LaTeX + BibTeX 全支持
scientific-writing IMRAD 结构写作，支持 APA/AMA/Vancouver/IEEE 引用格式
paper-writing 研究成果 → 论文初稿，writer + verifier 双 Agent 工作流
research-paper-writer 按 IEEE/ACM 格式标准生成正式论文
academic-writing 学术写作专家，强制使用编号引用，只接受学术来源
ntu-dissertation-expert NTU EEE 硕士论文 LaTeX 模板专家，自动克隆模板 + 本地编译

个人感受：academic-research-skills 功能最全，从研究到写作到审稿一条龙。日常快速出稿用 scientific-writing 更轻量。

2.3 论文辅助类

技能名 功能简介
academic-deep-research 严谨的深度研究框架，每个主题强制 2 轮研究，3 个用户检查点
deepresearchwork 4 阶段综合研究：规划 → 采集 → 分析 → 验证
paper-summarize-academic 论文自动摘要，根据论文类型（方法/数据集/多模态等）动态选择分析模板
nature-data Nature 系列期刊的数据可用性声明撰写与 FAIR 元数据检查
nature-figure Nature 级别的科研图表制作（Python matplotlib 或 R ggplot2）
nature-paper2ppt 从论文生成学术报告 PPT，适合组会、文献分享
nature-polishing 学术英文润色，将中文草稿转为 Nature 风格英文

个人感受：nature-paper2ppt 特别好用，丢一篇论文进去就能出中文 PPT，组会汇报省了不少时间。paper-summarize-academic 读论文效率神器，自动根据论文类型选择分析策略。

三、文档处理

3.1 文档读写

技能名 功能简介
doc 读写 .docx 文件，支持标题、样式、表格，生成后可转 PDF 预览
pdf PDF 生成（reportlab）与内容提取（pdfplumber），支持视觉校验
document-pro 万能文档处理器：PDF/DOCX/PPTX/XLSX 全格式读写
fbs_bookwriter 长文档写作：书籍、手册、白皮书，支持断点续写和质量检查
software-copyright-materials 软件著作权申请材料自动生成（从实际代码生成，不是 AI 编造）

3.2 格式转换与 OCR

技能名 功能简介
pdf-ocr 扫描 PDF → Word，基于百度 OCR，智能识别文字页/插图页/封面
pdf-smart-tool-cn PDF 全能工具箱：转换、OCR、合并拆分、水印、加密解密
word-to-pdf Word 转 PDF，支持中文和 Emoji

个人感受：pdf-smart-tool-cn 是瑞士军刀级别的，基本上 PDF 相关的需求都能搞定。pdf-ocr 对付扫描件论文很管用。

四、内容发布与自媒体

4.1 平台发布

技能名 功能简介
csdn-publisher CSDN 文章自动发布，扫码登录 + 浏览器自动化，集成写作方法论
xiaohongshu-skills 小红书全套自动化：登录、发帖、搜索、互动、竞品分析

4.2 社交媒体与资讯

技能名 功能简介
agent-reach 一统 14 个平台：Twitter/X、Reddit、YouTube、GitHub、B站、小红书、抖音、微博、微信公众号等
daily-trending 每日热榜聚合：知乎、微博、百度、36氪、虎嗅、澎湃新闻等
douyin-downloader 抖音视频下载，提供链接即可解析
douyin-hot-trend 抖音热榜数据：热门视频、挑战、音乐，含热度值和跳转链接
douyin-mcp-server 抖音无水印下载 + 视频语音转文字（基于硅基流动语音识别）
wechat-article-search 微信公众号文章搜索，返回标题、摘要、发布时间
wechat-reader 微信公众号全文阅读器（突破 JS 渲染限制）

个人感受：agent-reach 堪称信息聚合神器，14 个平台一个入口。douyin-mcp-server 的语音转文字功能很实用，看抖音视频不用开声音了。csdn-publisher 写完文章一键发 CSDN，省去了手动排版的麻烦。

五、数据分析与网络搜索

技能名 功能简介
data-analysis 数据分析工作流：CSV/JSON/SQL 数据质量检查、趋势分析、分群对比
tavily-search AI 优化的网络搜索，返回结构化结果，支持深度搜索模式
weather 天气查询，基于 wttr.in + Open-Meteo，免费无需 API Key
pll-designer PLL 锁相环 PI 控制器参数计算（电力电子/新能源方向专用）

个人感受：tavily-search 搜索质量比普通搜索引擎好很多，专门为 LLM 优化过。pll-designer 虽然小众，但做电力电子仿真的时候能省不少手算时间。

六、浏览器自动化与编程

技能名 功能简介
playwright 浏览器自动化：导航、表单填写、截图、数据抓取、UI 调试
agent-browser 轻量级无头浏览器 CLI，结构化元素引用（@e1, @e2），无需 CSS 选择器
github GitHub 操作：Issues、PR、CI 状态检查、API 查询
prompt-engineering-expert 提示词工程专家：CoT、few-shot、XML 标签、角色提示等技巧

七、知识管理与生产力

技能名 功能简介
obsidian Obsidian 笔记库操作：搜索、创建、移动笔记，自动更新 wikilink
note-organizer Joplin 笔记管理：全文搜索、标签分类、Markdown/JSON/HTML 导出
ima-skill 腾讯 IMA 知识库：上传文件、导入网页/公众号文章、搜索、笔记管理
kdocs 金山文档（WPS 云文档）：创建/编辑/搜索/分享各类在线文档
aippt AI 生成 PPT，基于智绘高迪设计 Agent API
imap-smtp-email 邮件收发：支持 Gmail、Outlook、163 等多账号 IMAP/SMTP
ontology 知识图谱：结构化记忆体，支持实体/关系建模和图遍历

个人感受：obsidian 和 ima-skill 配合使用效果很好——IMA 管在线知识库，Obsidian 管本地笔记。aippt 生成 PPT 速度快，适合临时需要演示的场景。

八、MATLAB 相关

这几个技能是专门针对 MATLAB 开发的，属于比较垂直的工具：

技能名 功能简介
matlab-live-script 生成 MATLAB Live Script（.m 文件），带富文本格式
matlab-digital-filter-design 数字滤波器设计与验证（FIR/IIR 低通/高通/带通/带阻/陷波）
matlab-performance-optimizer MATLAB 代码性能优化：向量化、内存管理、性能分析
matlab-test-creator MATLAB 单元测试生成（基于 Testing Framework）
matlab-test-execution MATLAB 测试执行、覆盖率收集、CI/CD 集成
matlab-uihtml-app-builder 基于 uihtml 的 MATLAB 交互式 Web 应用开发

个人感受：做电力电子仿真经常用 MATLAB，这几个技能覆盖了从写代码、测试到优化的完整流程。matlab-digital-filter-design 做滤波器设计特别方便。

九、技能安装与管理

最后说下怎么发现和安装新技能：

技能名 功能简介
find-skills 技能搜索引擎：npx skills find [关键词]，从 skills.sh 生态中发现新技能
skill-creation 技能创建工具：从会话中提取模式，生成新的 SKILL.md

想装新技能？直接问 Agent “帮我找一个 XXX 的技能”，它会自动搜索并安装。

十、写在最后

盘点下来，55 个技能大致可以分成几类：

  • 学术党必备：文献检索 + 论文写作 + 论文辅助，覆盖从选题到发表的全流程
  • 文档处理万能工具箱：PDF/Word/PPT 全格式通吃
  • 自媒体运营利器：CSDN、小红书、抖音多平台自动化
  • 信息聚合：14 个平台统一入口，热榜日报一键生成
  • 专业工具：MATLAB、PLL 设计等垂直领域技能

说实话，很多技能装了之后还没深度使用过，但光是知道”有这个能力”就已经让人心安不少。以后用到了直接调就行，不用再去网上搜教程了。

如果你也在用 AI Agent，推荐从 find-skills 开始，搜索你感兴趣的方向，说不定已经有现成的技能等着你了。
