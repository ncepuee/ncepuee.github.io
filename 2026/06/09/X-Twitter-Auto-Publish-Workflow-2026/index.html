用 Claude Code 自动发推文：X (Twitter) 发布工作流完整指南

发表于 2026-06-09 分类于 效率工具

一、前言

手动发推文的过程其实挺繁琐的：打开浏览器 → 登录 → 写内容 → 调格式 → 发布。如果你同时运营多个账号，或者需要定期发布 AI 日报、技术分享等内容，这个重复劳动会消耗大量时间。

本文介绍一套基于 Claude Code 的 X (Twitter) 自动发布工作流，覆盖从素材收集 → 选题筛选 → 内容创作 → 自动发布的全流程。

六、X 发布的注意事项

6.1 推文格式

  • 短推文：≤280 字符（中文约 140 字）
  • Thread：多条串联，每条独立 280 字符限制
  • X Article：长文，需要 X Premium

6.2 常见问题

问题 原因 解决方案
点击发帖无反应 有弹窗遮挡 page.keyboard.press('Escape') 关闭弹窗
编辑器找不到 X 页面结构变化 用 force: true 绕过
发布后看不到 X 缓存 刷新个人主页
Chrome CDP 连不上 端口冲突 换端口或杀掉旧进程

6.3 安全建议

  • 不要在推文中暴露 API Key、密码等敏感信息
  • 使用 force: true 时确认内容正确再点击发布
  • 建议先用草稿箱预览，确认无误后再发布
  • 定期检查 X 账号的登录状态
