一、前言

手动发推文的过程其实挺繁琐的：打开浏览器 → 登录 → 写内容 → 调格式 → 发布。如果你需要定期发布 AI 日报、技术分享等内容，这个重复劳动会消耗大量时间。

本文基于实际跑通的完整工作流，介绍如何用 Claude Code + Playwright + Chrome CDP 实现从素材收集 → 内容创作 → 自动发布的全流程自动化。所有代码和配置都经过验证，踩过的坑也一并记录。

三、核心原理：Chrome CDP

Chrome DevTools Protocol (CDP) 是整个方案的核心。它允许程序通过 WebSocket 连接到 Chrome 浏览器，像用户一样操作页面。

3.1 为什么用 CDP 而不是新浏览器？

方案 优点 缺点
Playwright 新浏览器 干净、可控 没有 X 登录状态，每次要重新登录
Chrome CDP 复用已有登录状态 需要关闭 Chrome 后用特殊参数重启

CDP 方案是最实用的——关闭 Chrome，用带调试端口的参数重启，就能在不丢失登录状态的情况下控制浏览器。

3.2 启动 Chrome 带 CDP

为什么用独立 --user-data-dir？

Chrome 不允许默认用户目录开启远程调试（安全限制）。必须指定一个不同的目录。首次启动后需要手动登录一次 X，后续会保持会话。

6.2 发布按钮找不到

现象：[data-testid="tweetButton"] 匹配到 2 个元素

原因：X 页面有主编辑器和回复编辑器，两个都有 tweetTextarea_0

解决：用 getByTestId('primaryColumn').getByTestId('tweetTextarea_0') 限定范围，或用 .first() 取第一个

6.4 登录状态丢失

现象：页面跳转到登录页

原因：使用了新的 user-data-dir 或 Cookie 过期

解决：在弹出的 Chrome 窗口中手动登录一次，后续会保持

6.5 PowerShell 剪贴板超时

现象：execSync powershell ETIMEDOUT

原因：Windows PowerShell 启动慢或被安全软件拦截

解决：直接用 page.keyboard.type() 逐行输入，不用剪贴板

七、视频推文发布

除了文字推文，视频推文的传播效果通常更好。以下是用 MoneyPrinterTurbo 生成 AI 资讯视频并自动发布到 X 的完整流程。

7.1 生成视频

通过 MoneyPrinterTurbo API 生成短视频：

字幕参数要点（实战验证）：

  • font_size: 36 — 9:16 竖屏刚好，60 会溢出
  • text_background_color: false — 去掉黑底，更清爽
  • subtitle_position: "bottom" — 底部显示

视频素材关键：video_subject 中必须混入 Pexels 通用搜索词（technology、coding、programming 等），否则搜不到素材会黑屏。

7.3 上传视频到 X

视频推文比文字推文复杂——需要通过 input[type="file"] 上传文件：

关键点：

  • 文件 input 的 accept 属性包含 video/mp4,video/quicktime
  • 视频上传时间取决于文件大小（12MB 约需 1-2 分钟）
  • 必须先输入文字再上传视频，否则文字可能丢失
  • 上传完成后需要等待 X 处理视频，不要急于点击发布

7.4 视频推文 vs 文字推文

对比 文字推文 视频推文
发布速度 即时 需等上传（1-2分钟）
传播效果 一般 视觉冲击力强
技术难度 低（键盘输入） 中（文件上传）
素材来源 无 Pexels 免费素材
适用场景 日报、观点、技巧 AI 资讯、产品展示、教程
